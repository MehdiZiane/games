# Games

Collection de petits jeux codés en Python.

## Jeux disponibles

- [Snake](./snake/snake.py) — jeu classique avec Pygame

## Installation

Chaque jeu a son propre `requirements.txt`. Exemple pour Snake :

```bash
python -m venv venv
source venv/bin/activate  # ou venv\Scripts\activate sur Windows
pip install -r snake/requirements.txt
python snake/snake.py
```
